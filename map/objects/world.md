# World model & level files (`shared/world`)

Pure-Go package (no raylib) holding the level/world model from
`docs/LEVEL_MAKER_SPEC.md`: world definitions, levels, their two-file
format, the blob-47 autotile solver, the cell-property compiler, and a
`World` that answers queries across level edges. Built 2026-10-05 as build
order step 1; since 2026-10-06 (steps 3-4) the client and server load
the world through it and collide/validate against it.

## Why this shape

The server must be able to import it, so it has no graphics dependency;
the level maker and tests share the one solver implementation. Grids are
dense per-layer slices indexed `y*W+x` (D2), not per-cell structs.

## Shape

- **Definitions** — `Defs` from `world/terrains.toml` via `LoadDefs`/
  `ParseDefs`: `Sheet` (global tile index = `Base`+cell, `Cells` reserves
  the range), `Terrain` (id, priority, blob sheet or single `Tile` when
  `edges = false`, default blocks/surface/interaction), `Surface`,
  `Interaction` (`SpeedMultiplier`), per-tile `TileProps`. Blocking flags
  `BlockGround`…`BlockMagic`, `BlockAll`. `shared/world/defs.go`
- **Level** — `Level{Name, Pos, W, H, Isolated, Layers, Ground, Upper,
  Overrides, Props, Objects, Hash}`; `Ground` has terrain/tile/under/flags
  (`GroundLocked`), each upper layer tile/flags (`TileFlipH/V`).
  `NewLevel`, `SetTerrain` (unlocks), `SetOverride`/`ClearOverride`.
  `shared/world/level.go`, `props.go`
- **Files** — `<name>.level.toml` + `<name>.grid.gz`. `LoadLevel`,
  `SaveLevel` (atomic: temp + rename, grid first), `DecodeLevel`/
  `EncodeLevel` on bytes (deterministic, so `Hash` = SHA-256 of both is
  stable). The grid section order lives in one place,
  `Level.gridSections`. `shared/world/file.go`
- **Autotile** — `ReduceMask`, `BlobStates` (47 masks ascending = sheet
  cell order), `StateOf`; `SolveCell`/`SolveRect`/`SolveAround`/`SolveAll`
  read neighbours through `TerrainSource` (`LevelSource` = one level, void
  outside; `World.SourceFor` = level + neighbours). Void and `edges=false`
  terrains are joined, empty cells are not (D20); locked cells untouched
  (D3). `shared/world/autotile.go`
- **Properties** — `Compile(level, defs)`: blocking = OR of terrain + every
  tile (strictest wins), surface/interaction = topmost tile that declares
  one, else terrain; overrides win; empty/unknown ground blocks all (D30).
  `shared/world/props.go`
- **Game-side loading (2026-10-06)** — `Collider` (`Blocks(tx, ty,
  flag)`, `SpeedMultiplier(tx, ty)`), implemented by `World` and by
  `Grid` (open W x H, blocked outside; the fallback and a test helper).
  `World.Spawn()` (first `spawn` object in an exterior level, world
  pixels). `LoadMap(root)` → `Map{World, Collider, Spawn}`: the world, or
  the open 100x100 `Grid` at `shared.SpawnPoint` when there are no files;
  an error when they're present but broken. `LoadWorld` recompiles every
  level's properties (D32). `shared/world/collider.go`
- **World** — `LoadWorld(dir)`, `LoadDir(root)` (ok=false when there's no
  `world/`+`levels/`), `Add` (rejects overlap/duplicate name),
  `CheckPlacement`, `LevelAt`, `Neighbours` (by geometry; isolated levels
  have none), `BlockingAt`/`Blocks`/`SurfaceAt`/`InteractionAt` in signed
  world tiles, `TileOf(px)` (floors), `SolveBorders` (returns neighbours
  whose tiles changed, for the editor to rewrite), `SolveLevel`.
  `shared/world/world.go`

## Connected to

- Data: `world/terrains.toml` (placeholder terrains; their sheets are the
  flat-colour placeholders in `assets/tiles/` from `cmd/blobtemplate`) and `levels/` (`meadow`, `lake`,
  isolated `house_1`), generated by `sample_test.go`.
- Imports `game/shared` for `GameObject`, `CollisionType`, `TileSize`,
  `SpawnPoint` (the sample meadow's `spawn` object sits on it).

## If you change this

- **Grid layout or TOML shape:** bump `GridVersion`/`FormatVersion`,
  update the spec's "File formats" section, and regenerate `levels/`
  (`go test ./shared/world -run TestSampleLevels -update`) — the test
  fails if the checked-in samples drift from the generator.
- **Solver state order** (`BlobStates`): every blob-47 sheet's art is laid
  out in this order; changing it re-maps all ground art.
  `cmd/blobtemplate` draws the template and placeholders from it, and its
  `TestCommittedPlaceholders` fails until `assets/tiles/` is regenerated.
- **Blocking flag bits:** stored in grid files; never renumber, only add.
- **Hits** `cmd/blobtemplate`, `client/` (prediction, `client/render`) and
  `server/` (validation, spawn) — all import it. A change to `Compile`,
  the blocking flags or `SpeedMultiplier` changes what the anti-cheat
  flags; read `server-anticheat.md` first. **Does not hit** `animaker/`.
